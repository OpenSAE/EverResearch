# 模型维护

## 目的和主要功能

让科研任务从实际入口构造所选模型，取得预期输出并识别所用权重和附属资源。

## 适用范围

用于当前科研项目增加、修改或移除模型、变体及其资源。输入为目标模型、配置或权重和实际调用者。

从项目 `AGENTS.md`、README 或接入说明确定配置、登记和构造入口。先查任务实际使用的输出，再追到系列声明、模型实现和权重加载。项目有直接调用模型的工作流时，同时核对这些调用。

- **增加。** 登记可选择的新家族、系列、变体或资源。
- **修改。** 修改已有结构、前向、兼容性或权重选择，并同步使用这些结果的任务。
- **移除。** 移除指定变体、预设、兼容组合或资源。范围是整个模型时执行完整卸载，先处理剩余调用和共享实现。

[模型操作方案](references/procedures.md)说明系列布局、旧权重读取、三类改动的实施顺序和完成条件。按目标操作查阅。
