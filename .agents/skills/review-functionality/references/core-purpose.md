# 确定核心功能

## 目的和主要功能

说明如何结合结构图、注释和源码确定核心用途。

## 适用范围

适用于阅读目标文件并选择正常使用场景时。

## 操作备忘

1. 从用户指定的任务与文件开始，读取开头说明和相关实现。
2. 已有结构图时，用它定位文件在整体任务中的作用、输入和输出；阅读当前任务涉及的源码关系。直接阅读源码同样可以完成这项工作。
3. 用一句话说明：文件接收什么，为哪个任务产生什么结果。
4. 选择该用途的正常输入，写清预期结果，以及从哪个正式入口读取结果。

例如：给定特征编号，从解释库取得对应解释，并随实验结果保存。核心结果包括编号与解释的正确对应，以及保存后能够读取。

结构图与注释帮助理解，测试通过实际入口观察结果。相关文件共同完成一项功能时，共用这一场景。

后续遇到需要反复使用的具体阅读方法时，在本备忘录中补充相应操作。
