# 迁移与合并功能

## 目的和主要功能

保存依据实际职责迁移、合并实现并复用核心测试的操作方法。

## 适用范围

适用于跨文件整理功能时。

## 操作备忘

1. 从已确定的核心功能和实际调用关系出发，定位应负责该功能的模块。
2. 将同一功能集中维护，调用者使用共同实现；具体任务特有的行为归对应任务。
3. 同步改接调用者，移除旧实现及其专属转发、配置和测试。
4. 运行同一组核心功能测试，检查相同正常输入是否继续得到所需结果。

例如，多个入口分别解析同一个 SAE 的解释来源时，可将对应关系集中在负责资源记录的模块。解释获取和结果保存使用同一份记录，再用取得解释并保存读取的核心场景检查整体结果。

整理以功能职责和调用需要为依据。文件数量、统一命名和抽象层次提供辅助信息，实际结果决定整理是否达成目的。
