# 科研任务维护

## 目的和主要功能

让研究者和后续程序通过正常入口选择任务，使用完整结果和可解释的部分结果。

## 适用范围

用于当前科研项目增加、修改或移除任务、工作模式及结果接口。输入为目标任务、调用者和实际使用场景。

从项目 `AGENTS.md`、README 或接入说明定位正式分发、配置、任务实现和结果读取。明确所需数据和模型、任务的计算与指标，以及谁使用结果继续做什么。

- **增加。** 接入新的科研方法或可独立选择的模式。
- **修改。** 更新已有算法、参数、预检、指标或结果接口。
- **移除。** 移除指定模式、选项或输出。范围是整个任务时执行完整卸载，先处理下游读取和仍被其他任务调用的实现。

[任务操作方案](references/procedures.md)给出任务文件归属、改动顺序、正式入口与产物的核对方式。按目标操作查阅。
