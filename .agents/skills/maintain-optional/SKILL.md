# 科研项目的按需资产维护

## 目的和主要功能

脚本提供可以独立发起的操作，测试把行为预期变为可反复执行的检查，文档说明怎样理解、使用和维护项目，外部文件让项目使用可追溯的外部成果。科研项目强烈推荐维护数据集、模型和任务三类组件说明，供项目使用者和后续维护者直接查阅。

## 适用范围

用于增加、修改或移除科研项目的独立脚本、测试、文档和随项目保存的外部文件。适用于已接入或首次接触的项目。先从项目 `AGENTS.md`、README、现有命令和使用者找到真实入口。采用 ResearchHarness 布局时，分别从项目根目录的 `scripts/`、`tests/`、`doc/` 和 `third_party/` 查起。已有项目沿用有明确使用者的等价位置。

- **脚本。** 维护有独立操作者的批处理、汇总、导出和演示入口。正式任务计算由任务实现承担，通用调度由基础层承担。
- **测试。** 维护需要反复检查的公开行为、故障回归和共享样本。正式实验执行与结果比较使用 `maintain-experiment`。
- **文档。** 强烈推荐从 README 导航到 `doc/datasets.md`、`doc/models.md` 和 `doc/tasks.md`，每份集中说明共有参数，并为各真实组件或任务模式写明功能、入口和关键参数。
- **外部文件。** 维护正式调用所用的外部副本、版本、许可及更新关系。项目自有适配由调用它的组件或基础层负责。

[按需资产操作方案](references/procedures.md)列出各类资产的具体路径、启用条件、维护步骤和完成条件。根据本次资产类型查阅相应章节。
