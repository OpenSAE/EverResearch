# Identification of core functions

## Purpose

Description of how core uses are identified in conjunction with the structure, notes and source code.

## Scope

This applies to the reading of the target file and the selection of the normal scene.

## Organisation

1. Read the beginning notes and related realizations, starting with the tasks and files specified by the user.
2. When a structure chart is available, use it to locate the role of the file in the overall task, input and output; read the source relationship involved in the current task. Direct reading of the source code also completes the task.
3. One sentence: What is received in the document and what is the result for which mission.
4. Select the normal input for this use, write the expected results and read them from which public entry point.

For example, a given feature number obtains a corresponding explanation from the explanation library and saves it with the results of the experiment. The core result includes the correct matching of the number to the interpretation, as well as being readable after saving.

The structure charts and notes help understand, and test the results through the actual entry point.
