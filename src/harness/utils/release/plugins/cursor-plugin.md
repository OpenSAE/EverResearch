## Install in Cursor

Open Settings and find Plugins in Customize. Import the `plugins/cursor-plugin`
folder from the [EverResearch repository](@REPO@), or extract the
[Cursor plugin ZIP](@DOWNLOAD@/ever-research-@VERSION@-cursor-plugin.zip) and
import the extracted directory. For a team marketplace, select the repository
and its root Cursor marketplace manifest in the team settings.

Reopen the project in Cursor and ask the agent “Inspect this research project's
directory structure.” If your Cursor installation offers project skills only,
use the [project skills installer](@REPO@#install) with `--agent cursor`.
