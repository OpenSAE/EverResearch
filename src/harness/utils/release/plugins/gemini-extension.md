## Install in Gemini CLI

Extract the [Gemini extension ZIP](@DOWNLOAD@/ever-research-@VERSION@-gemini-extension.zip)
into a directory named `gemini-extension`, or use `plugins/gemini-extension`
from a local [EverResearch checkout](@REPO@).

```sh
gemini extensions install ./gemini-extension
gemini extensions list
```

Open a trusted project workspace in Gemini CLI and ask “Inspect this research
project's directory structure.”
