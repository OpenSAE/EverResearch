# Research project templates

## Purpose

Browse code, configuration, and documentation for nine research project templates. CUB-200 is the default ResearchHarness example.

## Scope

Copy a template into a separate workspace and follow its README to configure Python, input data and weights. The templates generate experiment artifacts when run.

| Template | What it demonstrates |
| --- | --- |
| [CUB-200](cub/README.md) | Bird image classification, training, and prechecks |
| [Depth Anything 3](depth_anything_3/README.md) | Depth, camera estimation, and multi-view export |
| [FastVLM](fastvlm/README.md) | Image captioning and visual question answering |
| [FlagEmbedding](flag_embedding/README.md) | Text retrieval and reranking |
| [LightEval](light_eval/README.md) | Language model evaluation |
| [LLMLingua](llmlingua/README.md) | Prompt and transcript compression |
| [RF-DETR](rf_detr/README.md) | Object detection and instance segmentation |
| [SAM2](sam2/README.md) | Prompted segmentation and video tracking |
| [VGGT](vggt/README.md) | Depth, camera estimation, and 3D reconstruction |
