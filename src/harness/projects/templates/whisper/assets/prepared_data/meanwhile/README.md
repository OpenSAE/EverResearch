# Meanwhile evaluation annotations

## Purpose and main function

Preserve the annotated clips used in the upstream long-form English speech evaluation.

## Scope of application

Use these reference spans for the Meanwhile dataset described in the [evaluation notes](../../../doc/data.md). The original `data/meanwhile.json` records source video IDs, clip boundaries, and manually reviewed captions for 64 segments. The source audio is referenced by the annotations and is obtained separately.
