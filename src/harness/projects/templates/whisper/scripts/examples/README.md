# Whisper evaluation notebooks

## Purpose and main function

Run the original examples for English and multilingual speech recognition evaluation.

## Scope of application

Use [LibriSpeech evaluation](librispeech_evaluation.ipynb) for English-only benchmarking and [multilingual speech evaluation](multilingual_speech.ipynb) to compare results across languages. The notebooks retain their original Colab setup cells and saved examples. For this checkout, install it into the selected notebook kernel and skip the cells that install the upstream Whisper package. Running the notebooks requires their respective datasets, the weights selected in each notebook, and the listed evaluation dependencies.
