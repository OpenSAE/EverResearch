# LeRobot project documentation

## Purpose and main function

This index connects LeRobot's public commands to their configuration, source, and project documentation.

## Scope of application

Use this index when installing LeRobot, locating an implementation, or checking a change to a local research workflow.

- [Environment](environment/README.md) covers dependencies, installation, local resources, and verification.
- [User guide](code/agent_guide.md) covers recording, training, and evaluating a robot policy.
- [Reference documentation](code/reference/source/index.mdx) covers supported hardware, simulations, datasets, and policies.
- [Source and verification](code/source_ownership.md) lists the owners of the relocated code.
- [Experiments and formal run choices](experiment.md) covers local run commands, measured timings, and checkpoint and output readback.

- [Maintenance and formal run choices](maintenance.md) records ownership, validation evidence, and run conditions.
