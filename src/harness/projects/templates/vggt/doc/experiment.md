## Scope

Use these commands after copying the template and configuring the inputs and model described in the [project README](../README.md).

Use `python main.py colmap --help` to select scene inputs and an output format. Use `python main.py read-colmap <manifest> <destination>` to unpack a recorded reconstruction.
