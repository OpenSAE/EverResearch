# Template maintenance

## Purpose

Keep the template runnable and document how its public entry points connect to the
project's configuration and components.

## Scope

Use this page when changing the template or validating it in a fresh checkout.

Review the [project README](../README.md) and [documentation index](README.md)
for the declared dependencies and public entry points. Configure data and model
locations for the current environment. Run the relevant bounded check and confirm
the resulting outputs through the project entry point.
