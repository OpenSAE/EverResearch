# SOH example images

## Purpose and main features

This asset contains the two original frames bundled with the Depth Anything 3 SOH demonstration. The command `da3 auto assets/examples/soh/files --experiment scene_geometry --show-config` uses the pair in filename order.

## Scope

Use these frames for the documented local demonstration and configuration preview. The source is `assets/examples/SOH/` in the original project checkout. Preserve the filenames and update both frames together if the example changes.
