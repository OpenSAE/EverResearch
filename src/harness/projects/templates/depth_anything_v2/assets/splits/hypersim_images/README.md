# Depth Anything V2 resources

## Purpose and main function

The original upstream Hypersim training and validation image/depth path lists.

## Scope of application

These files come from the Depth Anything V2 source snapshot. The project guides link to their usage and describe how to select local inputs.

The [four-scene RGB list](files/four_scene_images.txt) selects 100 original 1,024 × 768 validation images for the point cloud workload. The [timing input record](../../../tmp/timing_inputs/README.md) identifies the source scenes and their paired split.
