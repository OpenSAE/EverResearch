# SAM2 notebook example images

## Purpose and main features

`files/truck.jpg` is the fixed input for the notebook's foreground-point segmentation demonstration. It comes from `facebookresearch/sam2`, originally at `notebooks/images/truck.jpg`.

## Scope

Use this asset for the image predictor notebook and the example command in `doc/tasks.md`. The upstream notebook also shows `groceries.jpg` and `cars.jpg`. To run those cells locally, obtain those files from the upstream `notebooks/images/` directory and place them alongside `truck.jpg`. Update the notebook and its example points if the bundled image changes.
