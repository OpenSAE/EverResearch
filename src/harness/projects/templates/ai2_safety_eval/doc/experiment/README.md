# Bounded verification runs

## Purpose and main function

Record the checks of the installed classification and generation commands.

## Scope of application

These checks verify that the commands load original data, apply the selected model, compute metrics, and write readable reports. Each run records its sample count and effective settings.

- HarmBench response classification report
- GSM8K generation report
