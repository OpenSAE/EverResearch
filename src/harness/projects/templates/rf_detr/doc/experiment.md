# Detection training and prediction

## Purpose and main functions

Describe how to create and read this project’s local run outputs.

## Scope

Use these commands after copying the template and configuring the inputs and model described in the [project README](../README.md).

Use `python scripts/train_experiment.py fit --help` to select a detection recipe. Use `python scripts/train_experiment.py results <experiment-directory>` to read its configuration, metrics and checkpoints.
