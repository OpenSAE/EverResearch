# Demonstrations and Slurm launchers

## Purpose and main function

Locate the project demonstrations and distributed training submission scripts.

## Scope of application

Use this page to open example code or submit an existing training recipe.

The [examples](../scripts/examples/) contain the original notebook and interactive Gradio demo. The bundled [example assets](../assets/videos/) provide the demonstration clips. From the project root, use `python scripts/examples/gradio_demo.py` in its demo environment.

[Slurm launchers](../scripts/training/) retain the original Kubric and pseudo-label training recipes. Run them from the project root after configuring the original scheduler resources and data locations.
