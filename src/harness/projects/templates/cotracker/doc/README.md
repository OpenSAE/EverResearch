# CoTracker project guide

## Purpose and main function

Identify the project commands, their source, and the requirements and outputs of each research workflow.

## Scope of application

Use this index to install or verify the project, find code by responsibility, and read tracking results.

- [Environment](environment/README.md) covers installation, dependencies, and local resources.
- [Datasets](datasets.md), [models](models.md), and [tasks](tasks.md) describe the implementation and how to select it.
- [Configuration](conf.md) lists default settings and overrides.
- [Experiments](experiment.md) describes the tracking records and result reader.
- [Command dispatch and Python API](base.md) maps the entry points to their source.
- [Examples and batch scripts](scripts.md) lists the standalone demonstrations and launchers.
- [Sampling tests](tests.md) describes the regression test.
- [EverResearch maintenance](maintenance.md) records source migration, verification, and external inputs.
