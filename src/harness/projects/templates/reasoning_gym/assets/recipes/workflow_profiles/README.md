# Reasoning Gym workflow profiles

## Purpose and main function

Run small end-to-end timings with the existing official Qwen2.5 0.5B Instruct checkpoint and the procedural chain-sum dataset.

## Scope of application

These recipes select ten evaluation prompts or ten examples in each training split. They select the official Hugging Face checkpoint by repository ID. To use a downloaded snapshot, set the model field to its local directory. The [experiment report](../../../doc/experiment.md) records the exact commands and the estimates for larger workloads.
