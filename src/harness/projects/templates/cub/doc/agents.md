# Maintenance skills

## Purpose

Description of how corresponding components, parameters, experiments and maintenance methods for general works are found.

## Scope

The entry and skills division are set out in [Program job description](../AGENTS.md) (state how access is selected and actual changes checked when the project is maintained, e.g., see when the document is updated as it becomes available).

This template uses a relative link to find shared skills in ResearchHarness, with stand-alone projects being linked to the selected project access mechanism in sync. Skills determine how to maintain, and the actual commands, configurations and results are indexed from the project document. Sync project job descriptions and this page as the skills entry changes.
