# 中央工作区公共功能

## 目的和主要功能

提供项目路径登记所需的工作区定位，以及本机资料的原子保存和产物记录。

## 适用范围

用于查找本机项目、保存资源绑定与结构成果，以及记录独立工具在中央工作区产生的文件。

`central.py` 定位已登记项目的源码路径。`workspace.py` 提供原子文件写入和工作区产物日志。共享技能、资源绑定和结构成果命令由 `src/harness/projects/` 提供，文件处理和环境工具由 `src/harness/utils/` 提供。

[项目接入与本机资源](PROJECT.md)说明项目源码、数据、Python 和结构成果如何定位，适用于登记项目和管理本机资源。
